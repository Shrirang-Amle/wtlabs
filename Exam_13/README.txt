PHP Login Module Setup

1. Create a MySQL database by running the file:
   database.sql

2. Default database settings in config.php:
   Host: localhost
   Database: exam_auth
   Username: root
   Password: (empty)

3. Place this project inside:
   C:\xampp\htdocs\Exam_13

4. Open in browser:
   http://localhost/Exam_13/register.php

5. Features:
   - User registration
   - User login
   - Password hashing
   - Session handling
   - Cookie tracking
   - Logout
