# Currency Converter React App

This is a simple ReactJS currency converter that converts US dollars to Indian rupees.

## Features

- Input amount in dollars
- Convert dollars to rupees
- Uses React `useState` and event handlers
- Portable project structure with no hardcoded folder paths

## Run on Any System

1. Open the project folder in a terminal.
2. Install dependencies:

```bash
npm install
```

3. Start the development server:

```bash
npm run dev
```

4. Open the local URL shown in the terminal.

## Build for Production

```bash
npm run build
```
